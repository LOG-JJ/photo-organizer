파일 분류
═════════

JPG · NEF · MOV 파일을 종류별 폴더로 나눕니다.

  1. 「사진 정리」 프로그램을 열고, 왼쪽에서 「파일 분류」를 선택합니다.
  2. 「폴더 선택」을 누르고 정리할 폴더를 고릅니다.
  3. 이동할 위치를 확인하고 「선택한 파일 정리하기」를 누릅니다.
     확인창에서 「예」를 누르면 끝입니다.

남길 파일은 체크를 해제하세요.

「보기·정렬」에서 JPG · NEF · MOV 폴더의 보기·정렬을 바꿀 수 있습니다.
기본: 아주 큰 아이콘·날짜 오름차순. 상위 폴더의 보기·정렬은 변경하지 않습니다.
JPG는 찍은 날짜, NEF와 MOV는 수정한 날짜로 자동 정렬합니다.
「정리 후에도 이 설정 적용」을 끄면 분류 후 자동 적용하지 않습니다.

정리 예시

  여행사진\DSC_1234.JPG → 여행사진\JPG\DSC_1234.JPG
  여행사진\DSC_1234.NEF → 여행사진\NEF\DSC_1234.NEF
  여행사진\MOV_001.MOV  → 여행사진\MOV\MOV_001.MOV

• 선택한 폴더 바로 안의 파일만 정리합니다. 하위 폴더와 다른 확장자는 그대로 둡니다.
• 같은 이름의 파일이 이미 있으면 덮어쓰지 않고 원본을 남깁니다.
• 처리 결과는 프로그램 화면에만 표시합니다. 별도의 기록 파일은 만들지 않습니다.

왼쪽 메뉴에서 다른 도구로 바로 전환할 수 있습니다. 선택한 폴더는 유지됩니다.
