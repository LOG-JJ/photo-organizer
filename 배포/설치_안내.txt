사진 정리 1.0.5

설치하기
  1. PhotoOrganizer-Setup.exe를 실행합니다.
  2. 「설치」를 누릅니다.
  3. 바탕화면이나 시작 메뉴의 「사진 정리」를 실행합니다.

업데이트하기
  프로그램을 종료하고 새로 받은 PhotoOrganizer-Setup.exe를 실행합니다.
  기존 프로그램을 먼저 삭제할 필요는 없습니다.

사용하기
  왼쪽에서 날짜별 정리 · 파일 분류 · RAW/JPG 정리를 선택합니다.
  폴더를 고르고 목록을 확인한 뒤, 오른쪽 아래 실행 버튼을 누르세요.

지원 환경
  Windows 10 / 11, 64비트
  Python을 따로 설치할 필요가 없습니다.

삭제하기
  Windows 설정 → 앱 → 설치된 앱 → 사진 정리 → 제거
  보관 중인 사진은 그대로 유지됩니다.

다른 사용자에게 전달하기
  PhotoOrganizer-Setup.exe 파일 하나만 전달하면 됩니다.

이 배포본에는 코드 서명이 적용되어 있지 않습니다.
