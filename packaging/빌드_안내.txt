사진 정리 설치 파일 빌드

일반 사용자는 dist 폴더의 설치 파일만 실행하면 됩니다.
아래 내용은 새 버전을 만드는 개발자를 위한 안내입니다.

준비: Windows 10/11 64비트, Python 3.12 64비트, Inno Setup 6.7 이상.

PowerShell에서 실행:
  python -B tools/dev.py build
  python -B tools/dev.py verify

다른 위치의 Inno Setup을 쓰려면:
  .\packaging\build.ps1 -InnoCompiler "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"

빌드용 Python 패키지는 별도 가상 환경에 설치합니다.
버전 번호는 src\photo_organizer\version.py에서 관리합니다.
임시 파일, 검증 결과, 빌드 캐시는 .work 아래에만 저장합니다.
결과는 dist\PhotoOrganizer-Setup.exe에 저장합니다.
수정할 때마다 같은 파일을 교체하며, 버전별 설치 파일을 추가하지 않습니다.

글꼴 폴더와 라이선스 문서는 반드시 함께 포함해야 합니다.
빌드한 실행 파일은 Python 없이 실행되며, 설치·제거는 현재 사용자에게만 적용합니다.
일반 실행 중 작업 기록 파일은 생성하지 않습니다.
상세 개발 안내: docs\DEVELOPMENT.md
